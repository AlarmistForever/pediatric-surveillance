# Запуск без локального компьютера

Workflow `.github/workflows/daily-digest.yml` запускается ежедневно в 08:00 по Барнаулу и его можно запустить вручную из вкладки **Actions**.

В настройках репозитория GitHub нужно создать secrets:

- `NCBI_EMAIL` — адрес для идентификации запросов PubMed;
- `DIGEST_TO` — адрес получателя письма;
- `SMTP_USER` — Gmail-адрес отправителя;
- `SMTP_APP_PASSWORD` — отдельный 16-значный App Password Gmail, не обычный пароль.

App Password создаётся в Google Account после включения двухэтапной проверки. Обычный пароль Gmail в GitHub добавлять нельзя.

Workflow создаёт временную SQLite-базу на каждый запуск, выполняет поиск, screening, appraisal и формирует письмо. Если любой шаг не удался, отправка не выполняется. Готовые файлы сохраняются как артефакты запуска GitHub Actions.
